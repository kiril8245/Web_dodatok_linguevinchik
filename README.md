## Завдання до лабораторної роботи
**Тема:** Розробка функціональності Web-додатка мовою Javascript.

**Мета:** Ознайомитись із засобами мови Javascript та навчитись їх застосовувати для побудови Web-інтерфейсу користувача.

**Загальне завдання:** Розробити функціональність для статичних сторінок Web-додатку першої лабораторної роботи із використанням архітектурного шаблону **MVC (Model-View-Controller)**. 

**Умови виконання:**
* Використання чистого HTML5, CSS3, Javascript (Vanilla JS).
* Заборона використання сторонніх Web-фреймворків (ReactJS, AngularJS, VueJS).
* Організація коду у вигляді модулів (класів) стандарту ES6.
* Збереження стану додатку на стороні клієнта за допомогою `localStorage`.

## Структура та функціональність додатку
Додаток складається з наступних модулів:
1. **Model (`UserModel.js`, `StudyModel.js`)** — відповідає за логіку роботи з даними (збереження користувача, імітація сесії, масив слів для навчання).
2. **View (`UserView.js`, `StudyView.js`)** — відповідає за взаємодію з DOM та відображення даних на сторінках.
3. **Controller (`AppController.js`)** — забезпечує зв'язок між Model та View, обробляє події (сабміт форм, кліки кнопок).

### Основні функції:
* **Реєстрація та Вхід:** Збір даних з форм та збереження/перевірка через `localStorage`.
* **Профіль:** Динамічне виведення персональних даних авторизованого користувача та можливість виходу з акаунту.
* **Навчання (Робоча сторінка):** Інтерактивне перемикання карток зі словами та контроль знань (тестування) без перезавантаження сторінки.

## Як запустити проєкт локально
Оскільки проєкт використовує ES6-модулі (`type="module"`), його **обов'язково** потрібно запускати через локальний сервер для уникнення блокувань політикою CORS.

1. Відкрийте папку проєкту у Visual Studio Code.
2. Встановіть розширення **Live Server**.
3. Натисніть кнопку **Go Live** у нижньому правому куті редактора.
4. Проєкт автоматично відкриється у браузері за адресою `http://127.0.0.1:5500/`.

Linguevinchik — це клієнт-серверний Web-додаток для інтерактивного вивчення іноземної лексики. Додаток дозволяє користувачам ефективно запам'ятовувати нові слова за допомогою карток та перевіряти свої успіхи у режимі тестування. 

У цій версії (ЛР№3) проект було повністю переведено на клієнт-серверну архітектуру з використанням реактивного фреймворка **VueJS** та серверного середовища **Node.js**.

##  Стек технологій

**Frontend (Клієнтська частина):**
* HTML5 / CSS3
* Bootstrap 5 (Адаптивна верстка)
* JavaScript (ES6+)
* **VueJS 3** (через CDN для реактивності інтерфейсу)
* **Axios** (для асинхронних HTTP-запитів)

**Backend (Серверна частина):**
* **Node.js**
* **Express.js** (REST API маршрутизація)
* Middleware: `cors`, `body-parser`

**База даних:**
* **SQLite** (`sqlite3`) для постійного зберігання даних користувачів та словників.

##  Основний функціонал

* **Реєстрація та Авторизація:** Створення нового акаунту та безпечний вхід із перевіркою даних на сервері БД.
* **Профіль користувача:** Відображення особистої інформації авторизованого користувача (ім'я, email, дата народження, стать).
* **Режим "Навчання":** Інтерфейс для перегляду нових слів (флеш-картки). Слова завантажуються з бази даних асинхронно через API.
* **Контроль знань:** Динамічно згенерований тест для перевірки засвоєного матеріалу з миттєвою валідацією відповідей.
